# 🐾 PetConnect

Aplicación móvil para la gestión de mascotas y futura exploración
de servicios relacionados con su cuidado.

## 🚀 Avance de la primera entrega

### Gestión de usuarios
- Registro
- Inicio de sesión
- Consulta de perfil
- Edición de información personal

### Gestión de mascotas
- Registro de mascotas
- Consulta de mascotas
- Edición de mascotas
- Eliminación de mascotas
- Asociación mascota-usuario

### Tecnologías
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
- MVVM

## 📋 Gestión del proyecto

El proyecto se gestiona mediante GitHub Projects,
Issues, épicas, historias de usuario y sprints.
